本讲座主要围绕**证券组合管理**的核心概念、**马科维茨资产组合理论**以及**单一指数模型**展开，旨在帮助理解投资管理中的风险与收益权衡。
## 一、证券组合管理概述

### 1.1 证券组合的含义与意义
* **证券组合**：指个人或机构投资者所拥有的由股票、债券以及衍生金融工具等多种有价证券构成的一个投资集合。
* **证券组合管理的意义**：它带来了一次投资管理理念上的革命，将管理的重点从单一资产转向资产之间的相互关系及组合整体的风险收益特征。
* **组合管理的必要性**：核心在于**降低风险**并**实现收益最大化**。

### 1.2 证券投资的风险
风险可以从不同角度分类：
* **按来源分类**：市场风险、偶然事件风险、贬值风险、破产风险、流通风险、违约风险、利率风险、汇率风险、政治风险。
* **按性质分类**：
    * **系统性风险**：反映了各资产共同运动、无法通过资产组合中资产数目的增加而消除的风险，又称市场风险。
    * **非系统性风险**：只反映资产本身特性，并且可以通过增加资产组合中资产数目而最终消除的风险，又称个别风险或特质性风险。

### 1.3 证券组合的基本类型
根据组合的投资目标，可分为：
* 避税型证券组合
* 收入型证券组合
* 增长型证券组合
* 收入—增长型证券组合
* 货币市场型证券组合
* 国际型证券组合
* 指数化型证券组合

### 1.4 证券组合管理的基本步骤
组合管理通常包括以下五个核心步骤：
1. **确定组合管理目标**：设定收入、增长或均衡等大目标，并具体设定收益率水平。
2. **制定组合管理政策**：规定投资范围，并考虑客户要求和市场监管机构的限制。
3. **构建证券组合**：根据管理者的投资策略（积极进取型、消极保守型、混合型）构建组合。
4. **修订证券组合资产结构**：根据市场变化和目标调整，剔除或增加证券。
5. **证券组合资产的业绩评估**：定期评估组合的表现。

### 1.5 现代组合理论的形成与发展
现代组合理论的发展历程是金融经济学的重要组成部分：
1. **哈里·马科维茨**：于1952年系统提出现代组合理论，奠定了基础。
2. **单一指数模型**：1963年，马科维茨的学生**夏普**根据其模型建立了相对简化的单一指数模型。
3. **资本资产定价模型 ([[投资学/Lecture 8 资本资产定价模型 (CAPM)\|CAPM]])** ：20世纪60年代初期，金融经济学家开始研究马科维茨模型对证券估值的影响，从而产生了[[投资学/Lecture 8 资本资产定价模型 (CAPM)\|CAPM]]。
4. **B-S[[投资学/Lecture 4 衍生证券价值分析\|期权]]定价公式**：1973年，布莱克和斯科尔斯提出了以无套利均衡分析为基础的[[投资学/Lecture 4 衍生证券价值分析\|期权]]定价模型。
5. **21世纪的重点**：资产价格波动和投资管理的历史表明，应将重点放在科学地选择资产、确定最佳资产组合上，而非仅仅依赖资产价格预测。

## 二、马科维茨资产组合理论

### 2.1 马科维茨其人
* **Harry Markowitz** (1927—2023)
* 1990年诺贝尔经济学奖获得者 (与Miller和Sharpe共同获奖)

### 2.2 投资组合选择的两个阶段
马科维茨将选择投资组合的过程分为两个阶段：
1. **第一阶段**：从观察和经验开始，最终形成对未来可投资证券表现的信念。
2. **第二阶段**：从对未来表现的信念开始，最终选择投资组合。

### 2.3 前提假设
马科维茨理论的构建基于一系列关键假设：
1. **投资者是风险规避的**：要求获得与所承担风险相匹配的收益。
2. **投资者是理性的**：在收益相等时选择风险最低的组合；或风险相同，选择预期收益最高的组合。
3. **不考虑税收**。
4. **投资期限为一期**：投资者在期初根据效用最大化原则选择资产组合。
5. **市场是完善的**：无交易成本，风险资产可无限细分，投资者可进行卖空操作。
6. **投资者只关心风险资产的均值、方差以及不同资产间的协方差**：此条件通常在效用函数为二次型或收益率呈正态分布时满足。

### 2.4 期望收益与风险的衡量
* **期望收益 (E(r))** ：某个资产的未来收益率是随机的，期望收益是各种可能收益率与其出现概率的加权平均值，即 $E(r) = \Sigma_{i=1}^n P_i r_i$。
* **风险 (σ²)** ：用投资收益率偏离期望值的平均程度来衡量，通常用收益率的方差或标准偏差表示，即 $\sigma^2 = \Sigma_{i=1}^n P_i(r_i - E(r))^2$。

### 2.5 简化市场中的资产组合

#### 2.5.1 情形一：一个无风险资产 + 一个风险资产
* **投资组合的收益和风险** ：假设投资到风险资产上的财富比例为w，无风险资产为(1-w)。$$\tilde{r}_p=w \tilde{r}+(1-w) r_f$$
    * 组合期望收益：$E(\tilde{r}_p) = wE(\tilde{r}) + (1-w)r_f$。
    * 组合标准差：$\sigma_p = w\sigma$。

* **期望收益与标准差之间的关系**：通过消掉投资权重w，可得到 ：$E\left(\tilde{r}_p\right)=r_f+\frac{E(\tilde{r})-r_f}{\sigma} \sigma_p$
    * 这表示当市场中只有一个无风险资产和一个风险资产时，资产组合所有可能的风险-收益集合，又称**投资组合可行集**。 
![](https://files.mdnice.com/user/73277/e23b0edc-d61b-4ace-836f-1fc01da67436.png)

* **资本配置线 (Capital Allocation Line, CAL)** ：
    * 在“期望收益－标准差”平面中，该关系式对应一条通过无风险资产和风险资产的直线，即CAL。
    * **斜率**：等于资产组合每增加一单位标准差所增加的期望收益，即每单位额外风险的额外收益，有时也称为**报酬与波动性比率**。
    * **投资权重的变化**：
        * w=1：全部投资风险资产，组合与风险资产重合。
        * w=0：全部投资无风险资产，组合与无风险资产重合。
        * 0<w<1：同时投资风险资产和无风险资产。
        * w>1：向银行借入现金投资到风险资产中。
* **最优资产组合的选择**：
    * 在给定投资组合可行集内，投资者根据效用最大化原则选择资产组合。
    ![](https://files.mdnice.com/user/73277/6df38f0c-8a63-4a08-804a-b265cb58da8c.png)
    * 通常通过无差异曲线与资本配置线的切点来确定最优组合。
    * **实际情况**：若存贷款利率不同 (贷款利率高于存款利率)，则资本配置线会变为一条折线。
    ![](https://files.mdnice.com/user/73277/cc231322-4bce-45e0-ae78-819d17ab6fdf.png)



#### 2.5.2 情形二：两个风险资产的组合
* **投资组合收益与标准差**：假设投资到债券上的财富比例为w，股票为(1-w)。
    * 组合期望收益：$E(r_P) = wE(r_D) + (1-w)E(r_E)$。
    * 组合方差：$\sigma_P^2 = w^2\sigma_D^2 + (1-w)^2\sigma_E^2 + 2w(1-w)\rho\sigma_D\sigma_E$。
* **方差、协方差和相关系数**：
    * $D(X+Y) = D(X) + D(Y) + 2COV(X,Y)$。
    * $COV(X,Y) = E[(X - E(X))(Y - E(Y))]$。
    * $\rho_{XY} = COV(X,Y) / (\sigma_X\sigma_Y)$。
* **目标**：在收益率固定的情况下，承担的风险最小；或在同风险水平下，收益率最高。这本质上是求函数极值的问题。$min\ \sigma_P^2 = w^2\sigma_D^2 + (1-w)^2\sigma_E^2 + 2w(1-w)\rho\sigma_D\sigma_E$
* **最小方差权重公式 ($w_{min}$)** ：$w_{min} = \frac{\sigma_E^2 - \sigma_D\sigma_E\rho}{\sigma_D^2 + \sigma_E^2 - 2\sigma_D\sigma_E\rho}$。此资产组合分配下，对应组合可行线的最左侧拐点。
* **不同相关系数下的组合可行集**：图示表明，相关系数越低，组合风险分散的效果越好，可行集越向左弯曲。
![](https://files.mdnice.com/user/73277/bc37840f-4462-4194-babe-61480b277e42.png)

### 2.6 推广至多个资产
* **期望收益**：$E(r_P) = \Sigma_{i=1}^n w_i E(r_i)$，且 $\Sigma_{i=1}^n w_i = 1$。
* **组合标准差**：$\sigma_p = \sqrt{[\Sigma_{i=1}^n \Sigma_{j=1}^n w_i w_j \rho_{ij} \sigma_i \sigma_j]}$，即组合风险是组合内各个资产协方差的加权和。

### 2.7 重要概念
* **可行集 (Feasible Set)** ：投资者面临的所有可能的投资组合的集合。通过变换各种资产在组合中的权重，模拟出不同相关系数下各种组合的标准偏差和收益来求得。
* **有效边界 (Efficient Frontier)** ：投资者只会选择可行集中最小方差点上方的资产组合。这部分资产组合被称为全部资产组合的有效边界。![](https://files.mdnice.com/user/73277/504ba6d5-57fb-4af2-9220-10ad60a2d7a6.png)
  ![](https://files.mdnice.com/user/73277/64dc3811-c371-4292-a671-ecd7676d92e3.png)

### 2.8 系统性风险与非系统性风险的进一步探讨
* **风险分散**：资产组合可以有效地分散风险，但并不能完全消除风险。
* **非系统性风险**：由单个资产自身因素造成的收益不确定性，如公司总经理辞职、投资决策失误、被兼并收购等。
* **系统性风险**：由对市场中所有资产收益造成影响的不确定性因素导致，如[[投资学/Lecture 5 宏观经济与行业分析\|宏观经济]]环境变化、国际国内政治局势变化、石油危机等。
* **风险降低效果**：通过增加资产组合中风险资产的数量可以减少非系统性风险的影响。当资产组合中资产数少于10个时，增加资产对组合风险的降低效果显著；但一旦超过15个，组合的风险程度就非常接近系统性风险水平，再加入更多资产，风险降低效果非常有限。
![](https://files.mdnice.com/user/73277/d2c903e5-4947-4075-9a5c-8a885dffcdb0.png)

### 2.9 分散化的应用
* **规避个体风险**：例如，通过同时购买钢铁和矿山股票，可以降低投资组合受铁矿石价格波动的影响。
* **日常生活中的分散化**：例如“狡兔三窟”、中医开药讲究成分搭配、地主配置黄金字画和子女教育、富人移民海外及海外资产配置等。

### 2.10 分散化投资不足 (Under-diversification)
* **理论应然**：个人财富应尽可能降低与所在国经济状况的相关度，即尽可能投资外国资产，因为人力资本收入与所在国经济状况高度相关。
* **现实偏差**：French and Poterba (1991) 发现，美国、日本、英国的投资者绝大部分只购买本国股票。
* **原因**：国际投资壁垒、资本在不同国家转移的汇率/税收/政治风险、信息不对称、对冲不可交易产品的消费等。

### 2.11 马科维茨的贡献与局限
* **优点**：
    1. **简化投资分析难度**：将收益与风险明确为具体的数学概念。
    2. **严格证明分散化投资能有效降低组合非系统性风险**：提出不同风险证券之间的不完全正相关性会导致证券组合的风险实现分散。
* **缺点**：
    1. **计算量大**：对于拥有N个金融资产的市场，计算有效边界需要计算`N(N+1)/2`个方差和协方差构成的矩阵，当N达到1000时，计算量巨大。
    2. **假设太多**：例如对市场完善性的假设可能过于苛刻。

## 三、单一指数模型 (Single Index Model, SIM)

### 3.1 模型概述
* **提出者**：由William Sharpe在1963年提出，是现代投资组合理论的一个重要组成部分。
* **核心思想**：通过引入一个基本假设，即各种资产的收益率变动的**共同影响因素有且仅有市场回报**，极大地简化了组合投资理论的实践运用。
* **模型假设**：每一种证券的收益率主要由两部分组成：
    1. **系统性风险 (市场风险)** ：与市场整体波动相关的风险。
    2. **特异性风险**：只影响特定证券的风险，与市场波动无关。

### 3.2 模型公式
单一指数模型表示为：$R_i = \alpha_i + \beta_i R_M + \epsilon_i$
* **$R_i$** ：第i种证券的收益率。
* **$\alpha_i$** ：与市场无关的证券的预期收益（截距项）。
* **$\beta_i$** ：该证券相对于市场指数的敏感度，即市场风险系数。
* **$R_M$** ：市场指数的收益率。
* **$\epsilon_i$** ：特异性风险，代表除市场因素外的随机波动。

### 3.3 简化计算的假设
单一指数模型通过以下假设大大简化了计算：
* $Cov(R_M, \epsilon_i) = 0$：证券的特异性风险与市场因素不相关。
* $Cov(\epsilon_i, \epsilon_j) = 0$：一个证券的非系统风险对其他证券的非系统风险不产生影响，两种证券的回报率仅仅通过市场因素的共同反应而关联。
* 综合以上两点得出，$Cov(R_i, R_j) = \beta_i \beta_j \sigma_M^2 \quad (i \neq j)$

### 3.4 单一指数模型的应用

#### 3.4.1 确定资产组合的收益
* 对于包含n种资产、权重为ωᵢ的资产组合，组合收益率为 $R_P = \Sigma_{i=1}^n \omega_i(\alpha_i + \beta_i R_M + \epsilon_i) = \Sigma_{i=1}^n \omega_i \alpha_i + R_M \Sigma_{i=1}^n \omega_i \beta_i + \Sigma_{i=1}^n \omega_i \epsilon_i$。
* 根据大数定理，当资产数量n趋于无穷且权重ωᵢ趋于0时，公司特有的风险（$\Sigma \omega_i \epsilon_i$项）倾向于被消除，组合充分分散化后只剩下市场风险： $R_P  = \Sigma_{i=1}^n \omega_i \alpha_i + R_M \Sigma_{i=1}^n \omega_i \beta_i$，等分化： $R_P  =\frac{1}{n} \Sigma_{i=1}^n  \alpha_i +\frac{1}{n} R_M \Sigma_{i=1}^n  \beta_i$。

#### 3.4.2 资产组合的方差
* 组合的方差可以表示为：$\sigma_P^2 = \beta_P^2 \sigma_M^2 + \sigma_e^2$。
    * 其中，$\beta_P^2 \sigma_M^2=Var(R_M)\sum_{j=1}^N\sum_{i=1}^N (w_i w_j\beta_i\beta_j)$ 是系统性风险部分。
    * $\sigma_e^2$ 是非系统性风险部分。
* 在等权重情形下，非系统风险 $\sigma^2_e=\frac{1}{n^2}\Sigma_{i=1}^n  Var(\epsilon_i)$ ，若$Var(\epsilon_i)$有界，随着$n$的增大，$\sigma^2_e$趋向于$0$。这意味着，非系统性风险是可分散化的：$\sigma_P^2 = \beta_P^2 \sigma_M^2$。

### 3.5 与均值-方差模型的计算量对比
单一指数模型极大地减少了计算复杂性，例如构建一个包含50支股票的投资组合：
* **单一指数模型 (SIM)** ：需要估计 3 * 50 = **150个参数** ($\alpha_i$, $\beta_i$, $\epsilon_i$方差)再加上市场本身的波动率即可。
* **均值-方差模型 (Markowitz)** ：需要估计 50个期望收益率 + 50*(50+1)/2 = **1275个不同的方差和协方差**。
这表明SIM在实践中具有显著的优势。

## 四、小结
* **Markowitz的投资组合理论**：
    * 在观念上有两个重大突破：一是将收益与风险明确为具体的数学概念；二是提出不同风险证券之间的不完全正相关性会导致证券组合的风险实现分散。
    * 其局限性在于方差-协方差矩阵的计算异常复杂，在实际运用中存在挑战。
* **单一指数模型** ：
    * 通过引入资产收益率变动只受市场共同因素影响的基本假设，极大地简化了组合投资理论的实践运用。
    * 其核心思想是证券收益率由系统性风险和非系统性风险组成。

## 五、思考题 (部分讲义中提出的问题)
1. 为什么大多数金融资产都呈不完全正相关关系？试分别举一个资产收益高度正相关和高度负相关的例子。
2. 请分析资产的数量与资产组合风险的关系。
3. 什么是系统性风险和非系统性风险。
4. 从理论上说，最佳资产组合应如何确定。
5. 如果两项资产完全正相关，你能把它们组成一个方差为零的资产组合吗。
