#### **一、债券定价理论**

债券的**内在价值（或理论价格）** 是其未来现金流入的现值。计算简单债券价值的步骤如下：
1.  **选择适当贴现率**：这是投资者对该债券要求的收益率，可参考市场上其他类似债券的收益率进行调整。影响适当贴现率的因素包括政府债券的到期收益率（`R_n`）、信用风险报酬（`DP`）、流动性风险报酬（`LP`）、税收调整的利差（`TA`）、可提前偿还产生的溢价（`CALLP`）、可提前兑付产生的折价（`PUTP`）以及可转换性导致的折价（`COND`）。这些因素共同决定了`n`年期债券的适当贴现率 `Y_n`。
2.  **计算所有利息的现值之和**：债券到期日前的利息支付构成一笔年金，其现值之和可使用普通年金现值公式 `APV = C * [1 - (1+r)^-n] / r` 计算，其中 `C` 为利息，`r` 为每年适当贴现率，`n` 为利息支付总次数。
    *   **示例**：面值1000元、票面利率9%（每年付息一次）、期限10年、适当贴现率10%的附息债券，其利息现值总和为90 * [1 - (1+0.10)^-10] / 0.10 ≈ 553.01元。
3.  **计算本金的现值**：利用复利现值公式 `PV = FV / (1 + r)^n` 计算，其中 `FV` 是本金，`r` 是每年适当贴现率，`n` 是距到期日的年数。
    *   **示例**：承接上例，该债券本金的现值为 1000 / (1 + 0.10)^10 ≈ 385.54元。
4.  **将两个现值相加**：债券的价值是利息现值和本金现值的加总。
    *   **示例**：上例债券的价值为 553.01 + 385.54 = 938.55元。
    *   **债券价值计算公式**：`V = Σ[C / (1+r)^t] + F / (1+r)^M`，其中 `V` 为债券价值，`C` 为利息，`F` 为债券面值，`t` 为现金流发生的年数，`M` 为债券期限年数，`r` 为年度适当贴现率。

**对债券价格的几点说明**：
*   **债券价格和面值的关系**：
    *   当**票面利率 < 贴现率**时，价格 < 面值 → **折价债券**。
    *   当**票面利率 = 贴现率**时，价格 = 面值 → **平价债券**。
    *   当**票面利率 > 贴现率**时，价格 > 面值 → **溢价债券**。
    ![](https://files.mdnice.com/user/73277/83091e53-dc22-485e-8b23-3bde6544c756.png)

*   **影响债券价格的因素**：
    *   **适当贴现率**：债券价格与适当贴现率**反方向变动**。
    *   **影响适当贴现率的因素**：市场利率水平、公司信用风险。
    *   **时间**：随着到期日的临近，债券的价格逐渐趋近于面值。
    ![](https://files.mdnice.com/user/73277/db684e6a-2a12-476e-8ef2-b16fde16abf8.png)

#### **二、债券的收益率**

**1. 到期收益率（Yield to Maturity, YTM）**
*   **定义**：是能使债券未来的现金流的现值正好等于债券当前市场价格（初始投资）的贴现率。它是按复利计算的，考虑了货币的时间价值，能较好地反映债券的实际收益，是应用最广泛的指标。
*   **计算**：到期收益率的计算是计算债券价值的**逆过程**。公式为 `P = Σ[C / (1+YTM)^i] + F / (1+YTM)^N`，其中 `P` 是债券当前市场价格，`C` 是利息，`F` 是债券面值，`N` 为距到期日的年数。
*   **假设与内涵**：通常假设债券不存在违约风险和利率风险，投资者将债券持有至到期日，并且每次获得的利息按计算出的到期收益率进行再投资直至到期日。YTM 不仅反映了利息收入，还考虑了债券购买价格和到期价格之间的资本利得（损失），通常被看作是投资者从购买债券直至到期获得的**平均收益率**。
*   **零息债券的到期收益率**：由于零息债券只有一次现金流（本金），其YTM计算公式为 `P = F / (1+YTM)^N`。
    *   **示例**：1年期面值1000元零息债券，市场价格934.58元，其YTM ≈ (1000/934.58) - 1 = 7%。
*   **半年支付一次利息的债券到期收益率**：需先计算每期（半年）的到期收益率，然后将半年收益率乘以2，得出年到期收益率。
*   **两个利息支付日之间购买的债券到期收益率**：计算更复杂，需要考虑清算日距下一次利息支付日的天数占利息支付期天数的比例。
*   **关于到期收益率的两个错误观点**：
    *   错误观点一：认为只要将债券持有至到期，投资者获得的事后回报率就等于事前计算的到期收益率。
    *   错误观点二：认为一个债券的到期收益率高于另一个债券的到期收益率就意味着前者好于后者。
    *   **正确观点**：即使持有债券到期，到期收益率也不是准确衡量回报率的指标；收益率的不同可能反映了两种债券的风险不同，因此不能作为比较债券优劣的标准。

**2. 当期收益率（Current Yield, CY）**
*   **定义**：是年利息与债券当时的市场价格的比值。它仅仅衡量了利息收入的大小。
*   **公式**：`CY = C / P`，其中 `C` 为年利息，`P` 为债券当时的市场价格。
*   **与到期收益率的区别**：当期收益率仅考虑利息收入，而到期收益率同时考虑了利息收入和债券的资本利得/损失。
*   **三者关系**：
    *   **平价债券**：票面利率 = 当期收益率 = 到期收益率。
    *   **折价债券**：票面利率 < 当期收益率 < 到期收益率。
    *   **溢价债券**：票面利率 > 当期收益率 > 到期收益率。

#### **三、久期与凸性**

**1. 债券价格与收益率关系**
*   **债券价格与收益率反方向变动**，这是债券价值的一个重要的普遍性规律。
*   当收益率很高时，债券价值很低；当收益率接近于零时，债券价值会趋近于现金流的总和。
*   **价格-收益率曲线是凸状的**，表明价格收益率关系是**非线性**的。

**2. 利率风险的衡量方法**
*   **全景法（Full Valuation Approach 或 Scenario Analysis Approach）**：已知利率如何变化，用估值技术计算出每一种变化对价格的影响。理论上模型好时非常精确，但缺点是复杂。
*   **久期/凸性法（Duration/Convexity Approach）**：将利率变化限制在利率曲线平行移动的场景下。

**3. 久期（Duration）**
*   **定义**：久期是衡量**债券价格对收益率变化的敏感性**的指标。它等于价格变化的百分比除以收益率变化的百分比。
    *   **公式**：`D = - (dP/P) / [dy / (1+y)]`，其中 `P` 为债券初始价格，`dP` 为价格变化值，`y` 为初始收益率，`dy` 为收益率变化值。
*   **久期的规则（影响因素）**：
    1.  **票面利率**：在其他因素不变的情况下，**票面利率越低，息票债券的久期越长**。因为票面利率越高，早期的现金流现值越大，其在债券价格中的权重越高，导致时间的加权平均值（即久期）越低。
    2.  **到期收益率**：在其他因素不变的情况下，**到期收益率越低，息票债券的久期越长**。因为到期收益率越低，后期的现金流现值越大，在债券价格中所占的比重越高，导致时间的加权平均值（即久期）越长。
    3.  **到期时间**：一般来说，在其他因素不变的情况下，**到期时间越长，久期越长**。债券的到期时间越长，价格的利率敏感性越强，这与久期越长是一致的，但久期并不一定总随着到期时间的增长而增长。
*   **久期的计算方法**：
    *   **有效久期（Effective Duration）**：可应用于附有选择权的债券的利率风险衡量。其计算方法利用收益率上升和下降时价格变化幅度的平均值来近似。
    *   **麦考利久期（Macaulay Duration）**：最早的久期计算方法，衡量债券预期现金流的加权平均到期时间，代表投资者拿回投资的本金和利息的平均时间。单位是年。
        *   **示例**：3年期面值1000元、年利率5%的年付息债券，目前市场利率也为5%。其麦考利久期约为2.86年。零息债券的麦考利久期等于其到期时间，而附息债券的麦考利久期小于其到期时间。
    *   **修正久期（Modified Duration）**：从麦考利久期衍生而来，考虑了目前的收益率。
        *   **公式**：`修正久期 = 麦考利久期 / (1 + 市场收益率)`。
        *   对于普通债券，麦考利久期和修正久期非常接近。但两者都无法应用于嵌有选择权的债券，因为它们都是以未来现金流为基础进行计算的。



*   **用修正久期估计价格波动的不足**：
    *   修正久期估算价格波动时，假定债券价格的变动百分比与收益率的变动值成正比，即价格变动百分比相对于收益率变动值的函数是一条直线。
    *   在价格-收益率曲线上，久期估计的直线在初始点与实际曲线相切。
    *   对于**小幅**的收益率变动，久期估计的价格波动十分接近实际波动。
    *   然而，随着收益率变动**越来越大**，久期估计的直线与实际曲线的距离也越来越远，估计值越来越不准确。
    *   久期估计的直线始终位于实际曲线的**下方**。因此：
        *   当收益率**上升**时，实际价格波动较小，使用久期会**高估价格的下降幅度**。
        *   当收益率**下降**时，实际价格波动较大，使用久期会**低估价格的上升幅度**。
     ![](https://files.mdnice.com/user/73277/43bd412e-676b-4074-a56a-2f188068f307.png)

**4. 凸性（Convexity）**
*   **定义**：凸性是对价格-收益率曲线非线性关系的衡量。久期对应的是价格-收益率函数的一阶导数，而**凸性可以看作是对久期估计误差的修正**，它与价格-收益率函数的二阶导数相关。
$$
d P=\frac{d P}{d y} \cdot d y+\frac{1}{2} \frac{d^2 P}{d y^2}(d y)^2+\varepsilon \quad \text {（ } \varepsilon \text { 为误差项）}
$$
*   **作用**：为了更精确地估计债券价格变化，尤其是在收益率变化较大的情况下，必须考虑价格收益率曲线的凸性性质。泰勒级数的前两项可以更准确地计算收益率变化导致的价格变化，其中第二项就包含了凸性。
*   **凸性与价格波动的关系**：
    *   当收益率变动较小时，凸性项可以忽略不计，久期估计准确。
    *   当收益率变动较大时，如果仅根据久期估计价格波动会产生较大误差。
    *   凸性的修正会在一定程度上消除久期的高估或低估，使估计的价格波动与实际情形更为贴近。
    *   **凸性不可能为负值**,因为价格关于收益率的二阶导总满足$\frac{d^2 P}{d y^2} >0$。 **凸性越大，对投资者越有利**。这意味着在其他条件都一样的情况下，**凸性越大的债券，在收益率降低时债券价格上涨的幅度就越大，在收益率升高时债券价格下跌的幅度就越小**。

*   **思考题解答**：**在其他条件不变下，如果预计市场会降息, 应该要投资长期债券还是短期债券? 要投资长久期还是短久期债券?**
    *   如果预计市场会**降息**，这意味着市场利率将下降。由于债券价格与利率**反向变动**，债券价格将上涨。
    *   **久期衡量债券价格对利率变化的敏感性**。**久期越长，债券价格对利率变化的敏感性越强**。
    *   因此，为了在降息时**最大化债券价格的上涨幅度**，投资者应该选择**久期较长的债券**。一般来说，**长期债券的久期比短期债券更长**。
    *   此外，**凸性越大的债券，在收益率降低时债券价格上涨的幅度就越大**。因此，在预期降息时，投资者也应倾向于选择**凸性更大的债券**，以获得更高的资本利得。
    *   **综上，如果预计市场会降息，投资者应选择长期债券和长久期债券，并且优先考虑凸性大的债券。**

#### **四、被动债券投资组合管理策略**

债券投资组合管理策略大体分为被动（消极）和主动（积极）两类。消极投资策略主要追求三个目标：为将来发生的债务提供足额资金；获得市场平均回报率；在既定的流动性和风险约束条件下追求最高预期收益率。

**两种主要的消极投资策略**：

**1. 负债管理策略**：
*   是银行、保险公司、基金等金融机构的核心业务，旨在满足未来债务偿还时的现金流支出需求并规避利率风险。
*   **目标期免疫策略（Immunization Strategy）**：
    *   **概念**：通过资产负债的适当组合，规避资产负债的利率风险，使资产负债组合对利率风险实现免疫。
    *   **原理**：利率波动会导致**价格风险**（利率上升，债券价格下跌；利率下降，债券价格上涨）和**再投资风险**（利率上升，再投资收入增加；利率下降，再投资收入减少），这两种风险对债券整体收入的影响正好相反。免疫策略的基本思想是通过将资产负债期限进行适当搭配，使两种利率风险相互抵消。
    *   **规避利率风险的两个条件**：**债券组合和负债的现值相等**；**债券组合和负债的久期相等**。
    *   **免疫策略的局限性**：
        1.  **久期是近似衡量**：久期只能近似衡量债券价格变化，无法精确消除利率风险。
        2.  **久期随市场利率和时间变化**：在整个目标期限内，债券组合和负债的久期会随着市场利率变化而不断变化，且两者变化并不一致，可能导致久期失配。
        3.  **久期非线性减少**：债券组合的久期并非随时间流逝而线性减少。
        4.  **收益率曲线假设不现实**：久期计算假定收益率曲线是水平的，且利率发生移动时整个收益率曲线平行移动，这与现实不符。

*   **现金流匹配（Cash Flow Matching）**：
    *   **概念**：通过构造债券组合，使债券组合产生的现金流与负债的现金流在时间上和金额上正好相等。这样可以完全满足未来负债产生的现金流支出需要，**完全规避了利率风险**。
    *   **最简单方法**：购买零息债券来为预期的现金支出提供恰当好的资金。
    *   **作用机制**：组合中的各债券都持有到期出售，消除债券价格波动风险；到期前利息收入直接用于支付当期现金流出，消除再投资的利率风险。
    *   **最大优点**：一旦实现现金流匹配，后期不需要再改变手中持有的债券组合。
    *   **现实运用局限性**：
        1.  **实现困难**：现金流匹配有时不容易实现。
        2.  **调整空间小**：一旦确定现金流匹配的债券组合，债券组合管理人很难再调整。

**2. 指数化策略（Indexation Strategy）**
*   **概念**：债券管理者构造一个债券资产组合，模仿市场上某种债券指数的业绩，使该债券资产组合的风险回报与相关债券市场指数相当。
*   与股票市场指数化策略相似，但由于债券市场指数自身特点，存在区别：指数构成成分变化频率、复制难易程度、构成成分流动性不同。
