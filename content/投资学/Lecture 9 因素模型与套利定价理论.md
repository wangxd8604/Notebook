# 因素模型与套利定价理论
## 一、因素模型

因素模型探讨了证券收益如何受各种经济因素影响。

### 1. 单因素模型

*   **提出背景**
    *   在估算中，协方差的计算量最大。
    *   经验表明，股票收益之间协方差通常为正，因为相同的经济力量会影响许多公司命运，例如经济周期、利率、技术进步、劳动力成本、原材料等。
    *   如果这些变量发生非预期变化，整个股票市场收益率也会相应发生非预期变化。
*   **核心假设**
    *   将所有公司外部因素组成一个**宏观经济指示器**，假定其影响整个证券市场。
    *   除了这个通常影响外，股票收益所有剩余的不确定性都是**公司特有**的。
    *   这意味着，证券之间相关性除了通常经济因素外，没有其他来源。
    *   内部特有因素对公司股价影响的期望值为零，且随投资分散化逐渐减少。
*   **模型公式**
    *   原始模型：$r_i = E(r_i) + m_i + e_i$ (1)
        *   $E(r_i)$：证券期初期望收益。
        *   $m_i$：非预期的宏观事件对证券收益的影响。
        *   $e_i$：非预期的公司特有事件的影响。
        *   $m_i$ 和 $e_i$ 的期望值均为零。
    *   扩展模型（单因素模型）：$r_i = E(r_i) + β_i F + e_i$ (2)
        *  $F$：宏观因素的不可预测成分。
        *  $β_i$：证券 $i$ 对宏观经济事件的敏感度。
        *  $m_i = β_i F$。
*   **存在问题**
    *   影响股票价格的宏观因素**不确定**。
    *   各宏观因素的**权重无法确定**。

### 2. 单指数模型

*   **提出**
    *   为解决单因素模型中宏观因素不确定性的问题，Sharpe 采用**一个股票指数代替宏观影响因素**。
*   **模型公式**
    *   $R_i = α_i + β_i R_M + e_i$ (3)
        *   $R_i$：股票 $i$ 的超额收益。
        *   $R_M$：市场超额收益。
        *   $α_i$：股票 $i$ 的特有收益。
        *   $β_i$：股票 $i$ 对市场超额收益的敏感度。
        *   $e_i$：公司特有的非系统风险。
*   **重要意义**
    *   **减少估算工作量**：从 $n(n+1)/2$ 减少到 $3n+1$。
        *   例如，沪深1400种股票，只需估算4201个数据。
    *   **方差和协方差计算**
        *   股票 $i$ 收益率的方差：$σ^2(R_i) = β_i^2 σ_M^2 + σ^2(e_i)$。
        *   两个股票超额收益率 $R_i$ 与 $R_j$ 的协方差：$Cov(R_i, R_j) = β_i β_j σ_M^2$。
        *   非系统风险独立于系统风险，$Cov(R_M, e_i) = 0$ 。
        *   $e_i$ 是每个公司特有的，它们之间不相关。
*   **几何表达**：**证券特征线**
	*  单指数模型可表达为一条截距为 $α_i$、斜率为 $β_i$ 的斜线。
    *   横轴为市场超额收益，纵轴为股票 $i$ 的超额收益。
    *   实际中通过回归得出。

*   **与 CAPM 模型的关系**
    *   **Beta 含义相同**：$Cov(R_i, R_M) = β_i σ_M^2$。
    *   **CAPM 是单指数模型的一个特例**：当所有股票 $α_i$ 的期望值为零时，单指数模型取期望后即为 CAPM 模型。
*   **局限性**
    *   将股票收益的不确定性简单分为系统风险与非系统风险两部分，与真实世界有距离。
    *   未考虑**行业事件**：影响行业内公司但不影响整个宏观经济的事件。

### 3. 多因素模型

*   **提出**
    *   系统风险包括**多种因素**。
    *   不同因素对不同股票的**影响力不同**。
*   **两因素分析模型**
    *   假定两个系统风险为**经济周期（GDP）** 和**利率（IR）** 的不确定性。
    *   模型：$R_t = α + β_{GDP} GDP_t + β_{IR} IR_t + e_t$。
    *   **示例**：天然气供应公司对 GDP 较不敏感但对利率敏感；五星级酒店对 GDP 敏感但对利率不敏感。单指数模型无力，两因素模型更合适。
*   **Chen, Roll and Ross (1986) 5因素模型**
    *   影响股票收益的5因素：
        *   **行业生产增长率 (IP)** 。
        *   **预期的通货膨胀率 (EI)** 。
        *   **非预期的通货膨胀率 (UI)** 。
        *   **长期公司债券对长期政府债券的超额收益 (CG)** 。
        *   **长期政府债券对短期国库券的超额收益 (GB)** 。
    *   模型：$R_{it} = α_i + β_i^{IP} IP_t + β_i^{EI} EI_t + β_i^{UI} UI_t + β_i^{CG} CG_t + β_i^{GB} GB_t + e_{it}$。
*   **Fama & French (1993, 1996) 3因素模型**
    *   影响股价的三个系统性因素：
        *   **市场指数 ($R_M$)** 。
        *   **小股票比大股票多的资产组合收益 (SMB)** ：Small Minus Big，基于公司规模。
        *   **高市场比率股票比低市场比率股票多的资产组合收益 (HML)** ：High Minus Low，基于账面价值/市值比 (Book-to-Market ratio)。
    *   模型：$R_{it} = α_i + β_i^{M} R_{t}^{M} + β_i^{SMB} SMB_t + β_i^{HML} HML_t + e_t$。
*   **CAPM 与 3因素模型为何会失败？**
    *   $SMB_t$：**小公司为何获得异常收益？** 小公司在经济不景气时承担**更高的经营和财务杠杆风险**。
    *   $HML_t$：**价值公司为何获得异常收益？** 价值公司在经济不景气时因**更高的杠杆和更具周期性敏感的收益**而风险更高 (Zhang, 2005)。
    *   以上的三因素模型最多只能预测5%，需要更多的因素。

*   **Fama-French (FF) 五因素模型**
    *   模型：$R_{it} = α_i + β_i^M R_t^M + β_i^{SMB} SMB_t + β_i^{HML} HML_t + β_i^{RMW} RMW_t + β_i^{CMA} CMA_t + e_{it}$。
    *   **RMW**：最盈利公司减去最不盈利公司的收益差 (Return spread of the most profitable firms minus the least profitable)。
    *   **CMA**：保守投资公司减去激进投资公司的收益差 (Return spread of firms that invest conservatively minus aggressively)。
    *   **关键信息**：
        *   新五因素模型有助于解释**小成长型组合的异常收益**。
        *   盈利能力因子（RMW）捕捉了**小公司中的违约风险**。
        
  *   **构建步骤**：
        1.  **数据收集**：市场回报率 (RM-RF)、规模因子 (SMB)、价值因子 (HML)。
        2.  **因素模型构建**：选择时间范围、计算因子暴露度（回归分析）、建立回归模型。
        3.  **投资组合构建**：评估股票预期回报、选择策略（因子加权、优化投资组合、分散投资）。
        4.  **持续监控与调整**：定期重新平衡、风险管理。


*   **其他相关概念**
    *   Smart Betas ETFs：考虑到特定公司或行业直接相关的因素，如盈利增长、股票动能、盈利能力。
    *   Factor War？Factor Zoo？：表明对发现更多“因素”的探讨。
    *   如何选择因素？。

## 二、套利

### 1. 定义与类型

*   **套利**：**投资者以零投资，在不承担任何风险的情况下，获取正收益的投资行为**。
*   **两类套利机会**：
    *   投资组合在期初有严格负的价格，但未来提供非负收益。
    *   投资组合在期初价格为零，但未来能获得正收益。

### 2. 套利示例

*   **简单例子**：IBM 股票同时在纽约交易所卖 60 美元，在纳斯达克卖 58 美元。可以在纳斯达克买入，纽约卖出，每股获利 2 美元，无资金投入。
*   **不同证券之间的套利机会**：
    *   通过将股票 A、B、C 按等权重构成投资组合 T，与股票 D 对比发现，在任何宏观环境下，投资组合 T 的收益率都高于股票 D。
    *   构建**零投资组合**（买入投资组合 T，卖空股票 D），可发现无论何种宏观环境，收益都为正。

### 3. 一价定律、价格的正定性与无套利

*   **一价定律 (Law of One Price)** ：对于任意两个投资组合，如果它们在未来每种状态下的收益都相同，那么这两个投资组合在当前的价格也应该相等。
    *   意味着零收益的证券其价格也必定等于零。
*   **价格的严格正定性 (Strictly Positive)** ：任给一个严格大于零的收益，该收益对应的证券组合的价格都要大于零。
*   **定理**：当价格函数同时满足**一价定律**和**严格正定性**时，市场是**无套利的**；反之亦然。

### 4. 套利与均衡

*   当套利机会出现时，投资者会通过低买高卖赚取差价收益。
*   套利行为导致证券供需变化，价格随之调整。
*   当达到某种水平使套利机会不再存在时，套利行为终止，市场达到**均衡状态**，证券定价处于合理水平。
*   这是资本市场理论的一个基本论点。

## 三、长期资本管理公司 (LTCM) 案例

### 1. 成立背景与操作策略

*   **成立年份**：1994年。
*   **创始人**：John Meriwether。
*   **核心团队**：包括诺贝尔经济学奖得主 Robert C. Merton 和 Myron S. Scholes。
*   **业务重点**：使用复杂数学模型进行**固定收益市场的套利交易**。
*   **操作策略**：
    *   **高杠杆**：杠杆比率高达 **25至30倍**。
    *   **交易方式**：市场套利，主要是固定收益产品。
    *   **市场影响**：通过大规模资本和精密策略影响市场价格。

### 2. 主要交易策略及风险

*   **当期债券与非当期债券**
    *   **背景**：新发行30年期政府债券（当期债券）流动性好，前一期债券（非当期债券）流动性差，市场给予非当期债券流动性补偿。
    *   **LTCM 策略**：买入非当期债券，通过回购融资对借来的当期债券进行担保（杠杆），赌利差缩小。
*   **房屋抵押债券 (IOs & POs)**
    *   **背景**：银行将抵押贷款剥离为仅付利息证券 (IOs) 和仅付本金证券 (POs)。利率变化影响两类证券现金流。
    *   **LTCM 策略**：认为 IOs 价格相对过低，买入 IOs，并买进国库券对冲，不猜测利率方向。
*   **欧洲货币一体化**
    *   **背景**：欧元推出前欧洲各国国债利率不一，意大利、西班牙等国债收益率高，德国国债收益率低。
    *   **LTCM 策略**：持有意大利、希腊等国政府债券，沽空德国政府债券，赌货币统一后利差缩小。
*   **意大利国债**
    *   **背景**：意大利政局不稳，国债利率高出德国国债8个百分点，甚至高于互换合约固定利率。
    *   **LTCM 策略**：买进意大利国债，买进固定利率互换合约，卖出浮动利率，获取套利收益。风险是意大利国债的信用风险。
*   **收益率曲线**
    *   **策略**：根据历史数据归纳收益率曲线经验值，若市场偏离，则进行套利 (如长期收益率偏高，短期偏低时，买入短期债券，沽空长期债券)。
*   **公司债信用利差**
    *   **背景**：公司债收益率通常高于国债。
    *   **LTCM 策略**：买进公司债，沽空国债获利（承担公司债违约风险）。
    *   **失败原因**：1998年俄罗斯金融风暴，资金涌向美国国债市场，A级公司债利差从60bp飙升至120bp，公司损失惨重。这是后期扩大规模后利润较小且导致重大亏损的交易。
*   **基于股票波动率的交易**
    *   **沽空隐含波动率**：
        *   **背景**：期权定价中波动率是唯一不能观测的，但可根据交易价格算出隐含波动率。1998年初市场经历亚洲金融风暴，隐含波动率过高。
        *   **LTCM 策略**：抛售股票期权波动度，通过投行卖出5年期股票期权，同时卖出看涨期权和看跌期权，不看方向，只赌隐含波动率下降。
        *   **风险**：隐含波动率高于历史波动率不等于高于未来真实波动率；每日结算制度导致波动率每日变化影响巨大；头寸太大，隐含波动率上升1%即损失4亿美元。
    *   **员工认股权证**：买进认股权证，卖出标普500看涨期权（员工为套现便宜卖出认股权证）。
    *   **标普500备选股**：在指数调整前买入标普500的备选股，赌其入选后基金配置增加带来短线超额收益。关键在于公告日而非调整日。

## 四、套利定价理论 (APT)

### 1. 理论基础

*   **提出者**：Stephen Ross 于 1976 年。
*   **核心思想**：利用**套利原理**推导出市场均衡状态下的资本资产定价关系。
*   **优势**：与 CAPM 具有相似的解释功能，但**涉及较少假设条件，更贴近现实**。

### 2. APT 的基本假设

*   证券收益率的变动是由**单因素或多因素模型**的变化所决定；市场所有参与者对资产收益率有相同的信念，且都能用同一个因素模型表示。
*   市场中**风险资产的个数远远大于系统性风险的种类数**。
*   市场中**不存在套利机会**。

### 3. 套利定价模型推导

*   **前提**：假设存在一个初始投资为零的投资组合。
*   **通过 $w_i$ 的选择使投资组合满足**：
    1.  每个资产上的投资金额在总财富中的比例都很小 ($w_i ≈ 1/n$)。
    2.  投资组合中包含足够多的资产 ($n$ 足够大)。
    3.  $w_i$ 的取值能够使投资组合对**所有系统性风险的敏感度都等于零**。
*   **大数定理应用**：当 $n$ 足够大时，公司特有风险 $e_i$ 的加权平均值趋近于零。
*   **结果**：该零投资组合的收益成为一个确定的值，且根据无套利假设，其收益必须等于零。
*   **期望收益的线性表达式**：$E(r_i) = λ_0 + λ_1 b_{i1} + ... + λ_k b_{ik}$。
    *   $λ_0$：当所有敏感度 $b_ik$ 为零时，期望收益为 $λ_0$。对于无风险资产，敏感度为零，所以 $λ_0 = E(r_f) = r_f$。
    *   $λ_k$：表示纯因素组合 $δ_k$ (对第 $k$ 种系统风险敏感度为1，对其他为0) 的期望收益减去无风险收益率 $E(r_{δ_k}) - r_f$。
*   **APT 基本形式**：$E(r_i) = r_f + (E(r_{δ_1}) - r_f) b_{i1} + ... + (E(r_{δ_k}) - r_f) b_{ik}$。

### 4. “纯因素”组合的构造

*   **定义**：一个对特定系统性风险敏感度等于1，而对其他风险敏感度为0的投资组合。
*   **构造步骤**：
    1.  先使组合中**其他因素的影响系数为零**。
    2.  通过适当的借入借出资金使组合**受单一因素的影响系数为1**。

### 5. APT 与 CAPM 的比较

*   **相同点**：
    *   理念相似：均衡时，个别证券的预期报酬率由无风险报酬率加上风险溢价决定。
    *   都说明了风险与报酬之间的理性原则：**更多系统性风险，更高预期报酬**。
    *   当**只有一个共同因素（如市场收益率）**能影响证券收益时，两者一致。
*   **区别**：
    *   **风险因素**：CAPM 纯粹从**市场投资组合**探讨风险与报酬关系，认为市场风险是唯一影响因素；**APT 认为不止一个经济因素**会影响证券报酬。
    *   **市场组合**：CAPM 所借用的市场组合**实际不存在**，只能借用单一股价指数；**APT 不需要市场组合**，只需设定若干“因素”。
    *   **假设条件**：CAPM 假定了投资者的**风险厌恶**偏好类型；**APT 没有对风险偏好进行规定**，适用性增大。
    *   **因素明确性**：APT 没有说明哪些因素关系着证券的预期报酬率，不如 CAPM 单因素模型易于理解。
